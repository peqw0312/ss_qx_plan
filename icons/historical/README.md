# 历史旗帜图标包（21 面）

108×108 方版图标，沿用 [Orz-3/mini](https://github.com/Orz-3/mini) 的外轮廓与对角光泽，
可以直接挂到 Quantumult X 策略组的 `img-url=` 上。

现代国旗那套见 [`../flags/`](../flags/)。这里收的是**已经退出历史舞台的旗帜**，
外加几面现存的子国族旗（威尔士 / 苏格兰 / 英格兰）、以及一面**自绘的秦汉黑龙旗**（3 版配色）
—— 用来给「复古节点名」配图标。

## 秦汉 黑龙旗（自绘 · 三版配色）

![秦汉黑龙旗预览](_preview-qin-dragon.png)

秦、汉**没有传世旗帜实物**，也没有可用的现成矢量素材（FOTW 只收近现代旗帜，
GitHub 上没有历史旗帜合集）。所以这面是**按史实配色程序生成的自绘图形**。

**史实依据**

| 依据 | 出处 |
| --- | --- |
| 秦旗为**黑底** | 《史记·秦始皇本纪》：「更命河曰德水……**衣服旄旌节旗皆上黑**」 |
| 「黑龙」是水德祥瑞 | 秦文公出猎获**黑龙**，以为水德之瑞（《史记》《汉书》皆载） |
| 黑底朱绘是秦汉主色 | 秦汉漆器通行**黑地朱纹**，是这一时期最具辨识度的配色 |
| 纹样为**蟠龙** | 战国秦汉流行的蟠螭/蟠龙纹：兽形蟠曲、粗犷，不是明清那种细密鳞甲五爪金龙 |

| 文件 | 配色 | 说明 |
| --- | --- | --- |
| `QIN-DRAGON.png` | 黑底**朱龙** | 汉漆器风，最贴史实配色（推荐） |
| `QIN-DRAGON-GOLD.png` | 黑底**金龙** | 帝气版，视觉最醒目 |
| `QIN-DRAGON-SILVER.png` | 黑底**银龙** | 冷色高对比，暗色图标栏里最好认 |

三版共用同一条蟠龙（抬头蟠曲、颈粗尾尖、三趾爪、背脊收尾成鳍），
只是换了配色。生成器是纯几何程序（螺旋中轴线 + 等宽偏移求轮廓），
**不是描图也不是素材拼贴**，因此这 3 张没有任何第三方授权问题，可自由使用。

## 生成方式

图标由本地脚本 `make_hist.py` 生成（未随仓库发布）：

```
FOTW 位图 / lipis SVG / 自绘
  → 裁掉外部白框（要求至少 3 条边是背景色才动手，避免啃掉旗面本身的白条）
  → cover（中心裁正方形）或 contain（整旗缩小 + 主色补边）
  → 缩放 108 → 叠 Orz-3 对角光泽 → 套 Orz-3 外轮廓
```

`cover` / `contain` 是逐旗定的：像黄龙旗、苏联旗这种有主体图案的用 `contain`
（补边色自动取旗帜主色，黄龙旗补黄、苏联旗补红，视觉上无缝）；
纯条带旗用 `cover`，这样条纹比例不会被压变形。
