二、Safari 那一条，必须单独说清楚

圈X 不认识「浏览器」，只认识域名。
「让 Safari 走代理」在技术上等于「让 Safari 里访问的所有网站都走代理」—— 这几乎就是「全部走代理」了。

所以这一条的正确实现方式，是用规则表的兜底逻辑：国外网站走代理，国内网站走直连。这件事正好由你配置里原有的「全球加速」规则集承担，我没有动它。

换句话说：你要的 Safari 效果，在你保留「全球加速」这个选择的那一刻就已经成立了 —— 你在 Safari 里打开国外网站会自动走代理，打开国内网站会自动直连，不需要额外写任何规则。

这也回答了上一轮那个看似矛盾的问题：你要「只有几个走代理」，又列了「Safari」。这两条不能同时成立 —— 后者要求国外网站普遍可访问，那就必须有「全球加速」这种兜底。我按后者处理了。

三、怎么把它装上去

方式 A：导入配置文件（推荐，一次搞定）

  1. 把 QuantumultX_定制版.conf 发到手机上，存进「文件」App（iCloud Drive 里最方便）。
  2. 打开圈X → 设置 → 配置文件（你的版本可能叫「其他设置」里的「配置文件」）。
  3. 选择从文件导入 / 从本地导入，选中那个 .conf 文件。
  4. 导入成功后，圈X 会用它作为当前配置。这时先把配置的自动更新关掉，否则下次更新会把你这份覆盖回原版。
⚠️ 一个必须知道的取舍：导入本地配置后，墨鱼原作者的后续更新不会再自动进来。以后你想跟上原版，就把最新原版发我，我重新合并一份给你 —— 这个流程我可以重复做，不用你动手。

方式 B：在界面里手动加（保留原订阅的自动更新）

  1. 设置 → 策略组 → 添加：名称填 代理应用，类型选静态，然后依次加入这些选项：自动选择、direct、美国节点、香港节点、日本节点、狮城节点、台湾节点、proxy。
  2. 设置 → 分流 → 远程 → 添加：把下面 7 条逐条加进去，策略都选 代理应用。
  3. 设置 → 分流 → 本地 → 添加：加两条 host-suffix, threads.com, 代理应用 和 host-suffix, threads.net, 代理应用。

四、装完立刻验证（2 分钟）

  1. 打开 YouTube 或 Telegram，刷一下。
  2. 回到圈X → 请求记录（或叫「网络活动」），找到刚才那些请求。
  3. 看「策略」那一列，应该显示 代理应用，而不是 兜底分流 / 全球加速。
  4. 顺便看一眼国内 App（淘宝、微信）的请求，应该显示 direct。
如果国内请求显示的是节点名而不是 direct —— 那不是规则的错，是你没配 GeoLite2 数据库。
你配置里国内直连的两道保险（geoip, cn 和「国内网站」规则集）都是按 IP 判断的，必须查数据库。去 设置 → 其他设置 → GeoLite2，把来源填上配置里给的那两个链接之一，并打开「自动更新」。
这一条很可能就是你之前觉得「开了代理就卡」的真正原因。

五、三个坑，提前说

1. Discord 语音 / Telegram 通话可能不通

这两个的语音功能走 UDP。圈X 能不能转发 UDP，取决于你的节点支不支持 UDP，跟规则无关。如果你只是想看消息、刷视频，不受影响；要打语音，得用一个支持 UDP 的节点。

2. 别提前这条规则的位置

新增的 7 条规则集，位置卡在「广告终结者」之后。这个顺序不能往上调 —— 否则视频站的内嵌广告域名会先被送进代理，去广告就失效了。

3. 「自动选择」会来回切节点

你配置里 tolerance=0，意思是只要另一个节点快一点点就会切过去。节点频繁切换会造成断流，感受就是「莫名其妙卡一下」。
两个办法：① 在圈X 首页把「代理应用」手动锁到一个固定节点；② 把 tolerance=0 改成 tolerance=50。

第 ④ 处为什么必须改

这就是国内 App 变慢的根源。
你原配置的兜底是「走代理」—— 也就是只要前面没匹配上，一律送出国。而负责把国内流量「捞回来」的只有两道规则（geoip, cn 和「国内网站」规则集），两道都是按 IP 判断、都必须查 GeoLite2 数据库。数据库没配，两道全失效，国内 App 就一路掉到兜底出国 —— 这就是 Soul 慢的原因。

微信有专门的「微信直连」规则集护着，所以从来没这个问题。这就是「为什么偏偏是 Soul」。
代价（必须知道）：被墙、但没被收录进「全球加速」名单里的冷门国外站点，现在会直连、可能打不开。主流站点（Google、YouTube、X、Instagram、Telegram、GitHub 等）都在名单里，不受影响。
遇到打不开的国外站，把网址发我，我给你加进「代理应用」组。
仍然一个字没动：去广告 18 条重写、广告终结者规则集、节点订阅、全球加速、DNS 设置、MitM 主机名。
想整体回退到原版，重新导入墨鱼原配置即可；只回退第 ④ 处，把那一行还原成 final, 兜底分流。
